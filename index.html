设置 API（配置保存在本机）

推荐用本地代理：项目目录执行 python proxy_server.py，然后访问 http://127.0.0.1:8000/index.html，这里填 http://127.0.0.1:8000/api/v1。
直接填中转站地址（如 https://gorouter.app/v1）在浏览器里会被 CORS 拦截，报 Failed to fetch，这不是页面的问题。
开启后，内容会随系统提示词发送给模型。
提示：API Key 会保存在浏览器 localStorage。不要在公共电脑上保存自己的 Key。
